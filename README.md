# Cloud AI Interview Prep

A study site for junior Cloud + AI engineering interviews: Linux, Git & GitHub and Docker, from the basics to intermediate level.

- Concepts with command examples
- Searchable command cheat sheets
- 80 interview questions (basic, intermediate, scenario) with model answers
- Hands-on labs to run on your own Linux machine
- A 14-week study plan, flashcard drill and self-graded mock interview

Open `index.html` in a browser, or use the GitHub Pages site. Progress is saved in your own browser only.
